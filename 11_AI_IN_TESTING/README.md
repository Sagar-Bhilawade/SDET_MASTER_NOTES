# 11_AI_IN_TESTING

This section is for AI-assisted QA work that is bigger than one Playwright command or
one Copilot prompt.

Use it for:

- PR and Jira story analysis for QA impact
- AI-assisted test plan, functional case, regression case, and unit-test suggestion
- manual flow discovery and automation candidate selection
- converting manual flows into Playwright automation drafts
- automation coverage tracking
- bug drafting and defect-quality improvement
- agent/skill workflows that support QA work
- context management between skills, task-specific files, and agent handoffs
- AI basics for QA, Copilot context, model/mode vocabulary, prompting patterns, and
  interview-safe boundaries
- honest Selenium/Java AI-assistance patterns without claiming production agents
- VS Code + GitHub Copilot daily SDET workflows: Ask/Edit/Agent/Plan, custom agents,
  prompt files, skills, MCP, and context control

Keep the framing honest:

- AI accelerates analysis, drafting, and repetitive conversion.
- QA judgment still decides risk, assertions, coverage, and release confidence.
- Do not paste internal company code, PR text, Jira story content, or proprietary details.
- Do not claim production self-healing automation unless that is actually deployed and used
  in the product pipeline.
- AI output is draft material until Sagar reviews risk, priority, assertions, data,
  maintainability, and evidence.
